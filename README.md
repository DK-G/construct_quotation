# construct_quotation (見積項目出し_高精度化)

建築見積における「項目出し」を高精度化（工程チェーン展開・漏れチェック）するためのシステムです。

## 概要

本プロジェクトは、見積の「数量算出」ではなく、請求漏れによって原価を圧迫しやすい**「表に出ない必要な前工程（例: ジョイント処理、パテ処理、シーラー等）」の漏れを自動検知・展開するシステム**の構築を目指します。

### コアコンセプト
1. **表項目から前工程チェーンを全展開**: 仕上げ名（例: クロス貼り）を起点に、標準仕様書・JASSに基づく施工手順を自動展開。
2. **Recall（再現率）最優先**: 請求漏れを防ぐため、疑わしい項目は積極的に出力（過剰計上は許容し、人間が1クリックで削除する運用）。
3. **例外キュー（Human-in-the-loop）**: 確度ラベル（標準/条件付き/要確認/低確度）に基づき、人間が注意すべき箇所だけを集中的に確認できるUI設計。
4. **数量・図面解析のスコープ外**: CAD/PDF図面データからの数量算出やBIM連携は一切行わず、テキスト情報の整合性チェックに特化。
